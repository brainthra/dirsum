# Changelog

All notable changes to this project will be documented in this file.

The project follows Semantic Versioning.

## [Unreleased]

## [0.2.0] - 2026-08-08

### Added
- `--help` option.
- `--version` option.
- Validation for directory arguments.
- Error messages and non-zero exit statuses for invalid usage.

### Changed
- Invalid paths and extra arguments are now rejected explicitly.

## [0.1.0] - 2026-08-08

### Added

- Initial project structure.
- Initial `dirsum` command.
- Directory file and subdirectory counts.
- Optional directory argument with the current directory as the default.
